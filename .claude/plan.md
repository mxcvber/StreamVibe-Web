#### Tech Involved For Frontend

The frontend will be built with TypeScript, React, Next.JS, Tailwind CSS, Stripe and shadcn/ui

#### Tech Involved For Backend

The backend will be built with NestJS and Prisma ORM, using PostgreSQL as the primary database. Movie data will be sourced from the TMDB API and stored in PostgreSQL. During development, PostgreSQL and Redis will run in Docker containers.
